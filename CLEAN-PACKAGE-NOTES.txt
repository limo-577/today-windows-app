Today Windows App v1.3.1 - Clean Package

1. All project file and folder names use ASCII/English names only.
2. The app UI remains Chinese.
3. The Windows product name and shortcut can remain Chinese.
4. Build output names are now unambiguous:
   - Today-Setup-1.3.1-x64.exe
   - Today-Portable-1.3.1-x64.exe
5. Build and development BAT files use English console text to avoid encoding issues.
6. Recommended project path:
   C:\TodayApp\
   or another path containing only English letters/numbers.
