Today v1.5.1

- Active/running task is always pinned to the top of the task list.
- The floating window also pins the active task to the top.
- Tasks now support an optional note/details field.
- Notes are collapsed by default and can be expanded/collapsed from the task row.
- Notes can be edited from the existing task edit dialog.
- Deleting a task now also deletes all task-record/session entries with the same task ID.
- Existing task data remains compatible; old tasks simply have an empty note until edited.
