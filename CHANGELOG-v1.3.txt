今日 v1.3 优化版

本次不是单纯改界面，而是针对 Windows 长期运行做稳定性优化：

1. 真正独立悬浮窗
- Electron 独立 BrowserWindow，不受主窗口边界限制。
- 主窗口隐藏后悬浮窗仍可继续存在。
- 悬浮窗默认不占任务栏按钮。
- 记忆上次位置、大小、透明度和置顶状态。
- 如果换了显示器导致旧坐标不可见，会自动回到可见屏幕。

2. Windows 后台运行 / 系统托盘
- 点击主窗口右上角关闭，不再直接结束程序，而是隐藏到系统托盘。
- 后台继续执行任务到点提醒。
- 双击托盘图标可恢复主窗口。
- 托盘右键可以：打开今日 / 打开悬浮窗 / 真正退出。

3. 提醒可靠性
- 到点检查从 React 页面迁移到 Electron 主进程。
- 即使主窗口被隐藏，也会继续检查提醒。
- Windows 睡眠后恢复时，会检查睡眠期间刚刚到期的任务，减少漏提醒。
- 22:00 未完成任务同样由主进程检查。
- 点击 Windows 通知会恢复主窗口并跳回相应日期。

4. 计时器稳定性
- 原版依赖 setInterval 每秒减 1，窗口隐藏或系统繁忙时可能产生漂移。
- 新版改为根据绝对截止时间计算剩余时间，最小化/卡顿后仍能自动校正。
- 专注记录改用真实经过毫秒计算，减少计时误差。
- 结束当前专注、删除当前任务、清空正在计时的任务时会正确收尾记录。
- 暂停后切换日期再继续，不再把专注记录错误记到当前浏览日期。

5. 数据与窗口状态
- 任务、记录、主题继续保存在 Windows 本机 userData 目录。
- 主窗口位置和大小自动记忆。
- 数据写入使用临时文件再替换，降低写入中断导致 JSON 损坏的概率。

6. Windows 单实例
- 重复打开软件不会再启动多个后台实例。
- 再次启动时会直接唤醒已运行的主窗口。

7. 安全性
- nodeIntegration=false
- contextIsolation=true
- sandbox=true
- 页面只通过 preload 暴露的最小 IPC 接口访问本地能力。
- 软件运行逻辑不需要联网；任务数据保存在本机。

暂未重构的功能：
- “每天/每周/工作日重复”仍沿用原设计：提前生成一定数量的未来任务。
  这是为了不破坏现有数据结构。以后如果需要，可单独升级成永久循环规则系统。

建议：需要 Windows 原生通知时优先安装 NSIS 安装版；Portable 版在部分 Windows 环境下对系统通知的注册行为可能不如安装版稳定。

8. 开机启动
- 系统托盘右键菜单新增“开机自动启动”开关，默认不强制开启。
- 需要全天提醒时可自行勾选；不需要时保持关闭。
