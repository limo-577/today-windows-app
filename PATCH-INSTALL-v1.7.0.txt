今日 v1.7.0 补丁替换说明

建议先退出“今日”（托盘右键 -> 退出），然后覆盖以下文件：

src/TodayApp.jsx
electron/main.cjs
electron/preload.cjs
src/FloatWindow.jsx
package.json
package-lock.json

本版本没有新增 npm 依赖。
覆盖后可直接运行：

npm run build:portable

或同时生成安装版和免安装版：

npm run build:windows

注意：
1. 设置密码后请牢记密码，程序不保存明文，也没有找回密码功能。
2. 导入备份会覆盖当前电脑上的“今日”数据，建议导入前先导出当前备份。
3. 如果备份中启用了密码，恢复到新电脑后仍使用原密码。
